Персональное «супер-приложение» для набора мышечной массы. Управляется полностью из современного **Telegram WebApp (PWA)**, а бот выступает тонким шлюзом и интерактивным каналом уведомлений.

Проект создан с учётом поведенческих особенностей: пользователь забывает есть, ленится взвешивать порции и вбивать данные, ленится готовить сложные блюда и склонен к импульсивным покупкам.

> **Принцип автономности и приватности:** Никаких интеграций с банками, календарями, почтой, сном или шагомерами. Все данные хранятся локально в оптимизированной SQLite-базе с WAL-режимом.

## 🌟 Ключевые возможности

### 1. WebApp-First интерфейс (5 вкладок без сборки и фреймворков)
- **Сегодня:** Сводка калоража (Hero-прогресс), макросы БЖУ, чеклист воды, веса, добавок (креатин, протеин, омега-3, вит. D) и насущных задач.
- **Еда:** Дневник приёмов пищи, повтор вчерашнего дня в 1 тап, генератор рецептов по остатку калорий (шейки/смузи за 5-15 мин, до 1 500 ₸), склад (`pantry`) и список покупок.
- **Тренировки:** Генератор сплитов, быстрый лог упражнений одной строкой (`жим 60x8x3, разводка 12х10х3`), PR-рекорды, расчёт тоннажа, динамический график прогресса (inline SVG).
- **Деньги:** Контроль расходов, фиксация импульсивных покупок, расчёт «цены импульсов в днях еды и белковом эквиваленте», копилки с прогнозом, подписки с предупреждением за день и сальдо долгов с закрытием в 1 тап.
- **Ещё:** Задачи с умным переносом, полнотекстовые заметки, трекер привычек со стриками, AI-аудитор «Что улучшить» и управление памятью SQLite.

### 2. Умный ввод одной фразой (Smart Input)
- **Текст, голос или фото:** Один эндпоинт `POST /api/input` и умная строка ввода внизу каждого экрана.
- **Атомарная связь еды и расходов:** Фраза «купил сникерс за 400 тенге» одновременно пишет приём пищи и расход с общим `link_id`. Удаление или 5-секундный Undo убирает обе части.
- **Быстрый парсер без AI:** Регулярные выражения мгновенно логируют воду («вода 300», «выпил стакан воды») и вес («вес 74.8», «взвесился 75 кг») без расхода квот Gemini.
- **Разбор сложных тренировок:** «присед 100 5х5 @8.5» автоматически раскладывается на подходы, вес, повторения и RPE.

### 3. Алгоритмы для набора массы (Bulking Engine)
- **Детектор голода «Давно не ел»:** Если прошло $\ge 3.5$ часа с последнего приёма пищи и дефицит калорий $> 150$ ккал, бот присылает алерт с кнопками:
  - `🍽 Подобрать рецепт`
  - `⚡️ Быстрый шейк` (высококалорийный рецепт на 550 ккал за 60 секунд)
  - `⏳ Позже на 30 мин`
- **Тренировочный буст:** В дни тренировок суточная норма калорий автоматически увеличивается на **+10%**.
- **Белково-углеводное окно:** Через 10–60 минут после завершения тренировки приходит напоминание закрыть окно (30–40 г белка + быстрые углеводы).
- **Автопересчёт нормы:** При изменении веса на $\ge 2$ кг норма калорий и БЖУ автоматически адаптируется.

### 4. Финансы без банка и контроль импульсов
- **Импульсивные покупки:** Переключение флага `is_impulse` в один клик без перезагрузки страницы или через инлайн-кнопку Telegram.
- **Эквивалент в курином филе:** Превышение лимита импульсов наглядно пересчитывается: *«Потрачено 15 000 ₸ — это 6 кг куриного филе или 12 пачек творога для набора массы!»*.
- **Подписки:** Бот за 1 день присылает уведомление: *«Завтра списание 2 990 ₸ за Яндекс Плюс. Продлеваем?»*.
- **Долги:** Учёт кто кому должен, расчёт сальдо и кнопка «Закрыть долг» в 1 тап.

### 5. Инсайты и AI-аудитор «Что улучшить»
- **14-дневный шлюз данных:** Защита от поспешных выводов при нехватке статистики.
- **5 локальных SQL-детекторов:** Детекция дефицита калорий при наборе, долгих пауз между едой, нехватки белка в дни тренировок, застоя веса и перевеса снеков над домашней едой.
- **Еженедельные карточки с отменой:** Кнопка «Применить» реально вносит изменения (+200 ккал к норме, напоминание в расписание), а кнопка «Отменить» полностью откатывает их.
- **Проверка эффекта через 2 недели:** Планировщик автоматически оценивает результат: *«Совет сработал: +600 г за 2 недели! Масса растёт ✅»*.

### 6. Экономия ресурсов и хранилище
- **Одна SQLite с WAL-режимом:** Высокая скорость чтения и записи без внешних СУБД.
- **2-летний бенчмарк:** База при 2 годах активного использования (2190 приемов пищи, 3000+ трат, 600+ тренировок) занимает всего **~2.6 МБ** на диске (лимит < 20 МБ соблюдён с многократным запасом).
- **Zero Full Table Scans:** Все ключевые выборки покрыты композитными индексами (`EXPLAIN QUERY PLAN` подтверждает отсутствие `SCAN TABLE`).
- **Сворачивание истории:** Детальные записи старше 12 месяцев одной кнопкой `/storage` сворачиваются в сводные дневные итоги `daily_aggregates_archive` с последующим `VACUUM`.
- **Резервное копирование:** Скрипт `scripts/backup_db.py` выполняет `sqlite3 .backup` + gzip по схеме 7 ежедневных и 4 еженедельных архива.

## 🛠 Установка и запуск

### Вариант 1: Локальный запуск (Разработка и тестирование)

#### 1. Клонирование и виртуальное окружение
```bash
git clone https://github.com/sayanelemes/telegram-ai-bot.git
cd telegram-ai-bot

python -m venv .venv
# Windows PowerShell:
.\.venv\Scripts\Activate.ps1
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
```

#### 2. Настройка переменных окружения
Скопируйте пример конфигурации и заполните обязательные поля:
```bash
cp .env.example .env
```
В файле `.env` укажите:
- `BOT_TOKEN`: токен вашего бота от `@BotFather`
- `GEMINI_API_KEY`: ключ из [Google AI Studio](https://aistudio.google.com/)
- `WEB_APP_URL`: публичный HTTPS адрес вашего WebApp (для локального тестирования используйте [Cloudflare Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/) или ngrok, например: `cloudflared tunnel --url http://localhost:8000`)
- `DEFAULT_TIMEZONE`: `Asia/Almaty`
- `CURRENCY`: `₸`

#### 3. Запуск приложения (Бот + FastAPI + Планировщик в одном процессе)
```bash
python app/main.py
```
Сервер будет доступен по адресу `http://localhost:8000`, а бот начнёт опрос в режиме long-polling.

### Вариант 2: Запуск в Docker с Caddy (Production)

Для production развёртывания используется готовый стек с автоматическим получением Let's Encrypt SSL-сертификатов через Caddy:

1. Укажите ваш домен в `.env`:
   ```env
   DOMAIN=bot.yourdomain.com
   WEB_APP_URL=https://bot.yourdomain.com
   ```
2. Запустите стек:
   ```bash
   docker compose -f docker-compose.prod.yml up -d --build
   ```
3. Проверьте статус контейнеров и логи:
   ```bash
   docker compose -f docker-compose.prod.yml ps
   docker compose -f docker-compose.prod.yml logs -f app
   ```

## 📱 Ручная проверка (Сценарии тестирования)

1. **Вход и Onboarding:**
   - Отправьте боту команду `/start`. Пройдите опрос (пол, возраст, рост, вес 70 кг, активность, цель «Набор массы»).
   - Нажмите инлайн-кнопку «🚀 Открыть приложение» или кнопку Menu WebApp.
2. **Умный ввод еды и расходов:**
   - В нижней строке ввода введите: `съел протеиновый батончик за 600 тг`.
   - Проверьте, что в дневнике еды прибавились калории и белок, а в расходах появилась запись на 600 ₸.
   - Нажмите «↩️ Отменить» — обе записи синхронно удалятся.
3. **Быстрый лог воды и веса:**
   - Введите: `вода 500`. Водный баланс пополнится на 500 мл без ожидания AI.
   - Введите: `вес 73`. При сдвиге $\ge 2$ кг бот поздравит с прогрессом массы и пересчитает нормы КБЖУ.
4. **Быстрый лог тренировки:**
   - Введите: `жим 80x8x3, разводка 16х10х3 @8`.
   - Перейдите во вкладку «Тренировки»: отобразится тоннаж, зафиксируется рекорд (PR) и построится SVG-график.
   - Норма калорий на сегодня автоматически увеличится на 10%.
5. **Генерация рецепта для набора массы:**
   - Перейдите во вкладку «Еда» → «Подобрать рецепт».
   - Получите высококалорийный рецепт на остаток калорий дешевле 1 500 ₸. Нажмите «Записать приём пищи» — продукты автоматически спишутся из кладовой.
6. **Управление хранилищем:**
   - Отправьте боту команду `/storage` или откройте модальное окно в настройках WebApp.
   - Просмотрите точный размер базы, число строк по таблицам и нажмите «Архивировать записи старше года».
