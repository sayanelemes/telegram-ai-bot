Production-ready Telegram-бот для персонального учёта питания, калорий, макронутриентов и расходов с использованием **Google Gemini AI** (`google-genai` SDK).

---

## 📋 Возможности

- 🚀 **Интерактивный Onboarding при первом `/start`**:
  - Выбор пола, возраста, роста, веса, уровня активности и цели (похудение, поддержание, набор массы).
  - Валидация входных данных для защиты от экстремальных и опасных значений.
  - Персонализация: существующие пользователи сразу видят дневную статистику без повторного прохождения опроса.
- 🥗 **Расчёт нормы питания (Mifflin-St Jeor)**:
  - BMR (базовый метаболизм), TDEE (с учётом коэффициента активности).
  - Безопасный дефицит/профицит калорий и расчёт белков, жиров и углеводов.
- 📷 **AI-анализ еды по фотографии и тексту**:
  - Распознавание блюд, ингредиентов, оценка веса порций, калорийности и БЖУ через Gemini Vision.
  - Предварительный просмотр с кнопками подтверждения: «✅ Да, сохранить» / «❌ Отмена».
  - Полезные персонализированные рекомендации от AI без медицинских диагнозов.
- 📊 **Мониторинг прогресса за день**:
  - Динамический визуальный прогресс-бар: `████████████░░░░ 66%`.
  - Сравнение фактического потребления с персональной суточной нормой.
  - Детализация по каждому приёму пищи (время, состав продуктов, БЖУ).
- 📅 **История питания**:
  - Просмотр статистики за сегодня, 7 дней и 30 дней.
  - Интерактивная пагинация по дням.
- 🧾 **Учёт расходов по чекам и тексту**:
  - Распознавание чеков по фото: магазин, дата, перечень товаров, валюта и итоговая сумма.
  - Распознавание текстовых расходов на естественном языке (например, `«кофе 1200 тг»` или `«такси 2500 тг в Яндекс»`).
  - Финансовая статистика за сегодня, неделю, текущий месяц и распределение по категориям.
- ⏰ **Надёжная система напоминаний (APScheduler)**:
  - Напоминания о завтраке, обеде, ужине, воде (интервальное) и итогах дня.
  - Индивидуальная настройка времени и часового пояса пользователя (`ZoneInfo`).
  - Сохранение состояния в SQLite и автоматическое восстановление задач при перезапуске бота без блокирующих `sleep`.
- 🛡 **Безопасность и надёжность**:
  - Middleware ограничения частоты запросов (Rate Limiting).
  - Глобальный обработчик ошибок — пользователь никогда не увидит технический traceback.
  - Фильтрация логов: секреты и токены маскируются (`[REDACTED_SECRET]`).
  - Оптимизация и проверка изображений в оперативной памяти (Pillow) без сохранения на диск.

```

   ↓
Repositories (SQL-запросы и агрегации aiosqlite)
```

## ⚙️ Установка и запуск

### 1. Предварительные требования
- Python 3.11+
- Токен Telegram-бота от [@BotFather](https://t.me/BotFather)
- API-ключ Google Gemini от [Google AI Studio](https://aistudio.google.com/)

### 2. Клонирование и виртуальное окружение
```bash
git clone <repo-url> telegram-ai-bot
cd telegram-ai-bot

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 3. Настройка `.env`
Скопируйте пример конфигурации и заполните ваши ключи:
```bash
cp .env.example .env
```

Отредактируйте `.env`:
```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
GEMINI_API_KEY=AIzaSyExampleKeyForGoogleGeminiAPI
DATABASE_PATH=data/bot.db
DEFAULT_TIMEZONE=Asia/Almaty
LOG_LEVEL=INFO
MAX_IMAGE_SIZE_MB=10
RATE_LIMIT_PER_MINUTE=20
GEMINI_MODEL=gemini-2.5-flash
```

### 4. Запуск приложения
```bash
python app/main.py
```

## 🐳 Запуск через Docker

Приложение полностью готово к развертыванию в контейнере. База данных SQLite сохраняется на хосте в каталоге `./data`.

### Запуск одной командой:
```bash
docker compose up -d --build
```

### Просмотр логов:
```bash
docker compose logs -f bot
```

### Остановка:
```bash
docker compose down
```

## 🧪 Запуск тестов

Тестовый набор полностью изолирован и не обращается к реальному API Gemini или сетевым ресурсам:
```bash
pytest -v
```

Результат выполнения:

Покрытие тестов включает:
1. `test_nutrition.py`: Формулы Mifflin-St Jeor, BMR, TDEE, безопасные минимумы калорий и макросов, валидация границ.
2. `test_image.py`: Обработка и конвертация Pillow, проверка форматов, ресайз больших фото, ограничение размера.
3. `test_gemini.py`: Pydantic-валидация структурированных моделей еды, чеков и текстовых расходов, очистка JSON.
4. `test_repositories.py`: CRUD операции для всех сущностей в базе данных SQLite.
5. `test_expenses.py`: Агрегация расходов за день, неделю, месяц и по категориям.
6. `test_reminders.py`: Планирование задач в APScheduler, отключение, перенастройка времени и таймзон.
7. `test_handlers.py`: Сквозное тестирование цепочки онбординга, смены состояний FSM и отображения главного экрана.

## 📱 Сценарии использования в Telegram

1. **Первый запуск**:
   - Отправьте `/start`.
   - Заполните пол, возраст, рост, вес, активность и цель с помощью кнопок.
   - Получите рассчитанную дневную норму калорий и БЖУ.
2. **Учёт еды**:
   - Нажмите `🍔 Добавить еду` или `📷 Анализ фото`.
   - Отправьте фото тарелки с едой или текст (например, `«Овсянка 200г с бананом и кофе»`).
   - Бот покажет состав, вес и калории каждого продукта.
   - Нажмите `✅ Да, сохранить` — прогресс за день обновится мгновенно.
3. **Учёт расходов**:
   - Отправьте фото кассового чека или текст расхода (например, `«кофе 1200 тг»`).
   - Бот распознает заведение, категорию и позиции.
   - Подтвердите сохранение. Статистика в разделе `💰 Расходы` обновится.
4. **Напоминания**:
   - Откройте `⏰ Напоминания`.
   - Включайте/отключайте напоминания в один клик.
   - Меняйте время и часовой пояс под ваш регион.
